# تطبيق الطيبات 🍏
نسخة خفيفة باللغة العربية، مناسبة لهاتف Android محدود الذاكرة.

## تشغيل سريع
افتح `www/index.html` في المتصفح.

## بناء APK مجاناً عبر GitHub Actions
1. ارفع هذا المشروع إلى مستودع GitHub جديد.
2. ارفع مجلد `.github/workflows`.
3. من تبويب Actions شغّل `Build Android APK`.
4. بعد نجاح البناء، افتح نتيجة الـWorkflow ثم Artifacts وحمّل ملف APK.

ملاحظة: المشروع مستقل وغير رسمي، والمحتوى الغذائي معروض كمرجع للنظام المنسوب للدكتور ضياء العوضي.

## الهوية البصرية
تم استخدام أيقونة التفاحة الخضراء المقضومة التي زوّد بها المستخدم كأيقونة للتطبيق وفي الواجهة.
